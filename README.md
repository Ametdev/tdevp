# Теплый дом - Официальный сайт

Современный многостраничный сайт компании "Теплый дом" - стеклянные конструкции, окна, двери, жалюзи и кондиционеры в Евпатории.

## 🚀 Технологии

- **Astro** - статический генератор сайтов
- **TypeScript** - типизированный JavaScript
- **Tailwind CSS** - современный CSS фреймворк
- **Markdown** - для контента (товары, отзывы, галерея)

## 📦 Установка

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр собранного сайта
npm run preview
```

## 📝 Добавление контента

### Добавление товара

1. Создайте файл `src/content/products/название-товара.md`
2. Добавьте изображение в `public/images/products/`
3. Заполните frontmatter:

```markdown
---
title: "Название товара"
description: "Краткое описание (1-2 предложения)"
price: 15000
priceUnit: "руб"
priceNote: "от"  # опционально
category: "Стеклянные конструкции"  # одна из 6 категорий
image: "/images/products/your-image.jpg"
featured: true  # показать на главной
inStock: true
order: 1  # порядок сортировки
---

## Описание

Полное описание товара...

## Характеристики

- Характеристика 1
- Характеристика 2

## Преимущества

- Преимущество 1
- Преимущество 2
```

**Доступные категории:**
- Стеклянные конструкции
- Окна и защита
- Двери
- Подоконники
- Кондиционеры
- Жалюзи и шторы

### Добавление отзыва

1. Создайте файл `src/content/reviews/имя-клиента.md`
2. Опционально добавьте фото в `public/images/reviews/`
3. Заполните данные:

```markdown
---
author: "Имя клиента"
date: 2026-04-15
rating: 5  # от 1 до 5
avatar: "/images/reviews/avatar.jpg"  # опционально
---

Текст отзыва клиента...
```

### Добавление проекта в галерею

1. Создайте файл `src/content/gallery/название-проекта.md`
2. Добавьте фото в `public/images/gallery/`
3. Заполните данные:

```markdown
---
title: "Название проекта"
date: 2026-03-20
category: "Категория работ"
images:
  - "/images/gallery/project-1.jpg"
  - "/images/gallery/project-2.jpg"
  - "/images/gallery/project-3.jpg"
featured: true  # показать на главной
---

Описание выполненной работы...
```

## 🔍 Валидация контента

Перед сборкой автоматически запускается валидация контента:

```bash
npm run validate-content
```

Скрипт проверяет:
- Наличие обязательных полей
- Корректность значений (цены, рейтинги, категории)
- Существование файлов изображений

Ошибки записываются в `content-validation-errors.txt` для ручной проверки.

**Важно:** Валидация не блокирует сборку, только предупреждает о проблемах.

## 🌐 Деплой на GitHub Pages

Сайт автоматически деплоится на GitHub Pages при push в ветку `main`.

### Настройка

1. В настройках репозитория GitHub перейдите в **Settings → Pages**
2. В разделе **Build and deployment** выберите **GitHub Actions**
3. Файл `.github/workflows/deploy.yml` уже настроен

### Кастомный домен

Файл `public/CNAME` содержит домен `tdevp.ru`. 

Для настройки DNS у регистратора домена добавьте записи:
```

A     @     185.199.110.153
A     @     185.199.111.153
CNAME www   ametdev.github.io
```

## 🛠️ Дополнительные скрипты

### Парсинг существующего сайта

```bash
npm run parse-site
```

Загружает HTML с существующего сайта и извлекает контактную информацию в `parsed-data.json`.
